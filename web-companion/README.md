# Poi trip companion

Live: https://poi-trip-companion.dhanushriyan22.chatgpt.site

This mobile-first static companion uses the same Supabase Auth, event/photo storage, friendships, expense RPCs and feedback table as Android. The login page is publicly reachable with the owner's approval; data access is enforced by existing Supabase RLS, not by hiding buttons. `dist/config.js` contains only the intentionally public client configuration; never put service-role, Gemini or OAuth secrets there.

Use email/password (including Gmail addresses). Google appears only if the existing provider is enabled; Google OAuth and phone/SMS were not configured at this release. This is not Sign in with Apple and does not require an Apple developer account. On iPhone, use Safari → Share → Add to Home Screen. No offline-write queue or background geofence is promised: reconnect and confirm successful saves before assuming anything synced.

Included: exact-event share links and owner-created guest join links; full event details/location/live status/calendar export; owner editing/cancellation; private event invitations and acceptance; photo uploads without attendance/check-in, likes/comments/views; private expense groups/invitations; equal/exact/percentage/share splits and multiple payers; receipts, edits/soft deletion, expense comments/activity, recipient-confirmed settlements and CSV export; profile editing, Classic/Pulse/Retro and light/dark display; distance filtering with foreground location; date-wise event calendar and the reviewed January local calendar in English/Kannada; private tester feedback/history.

Join links use 64 hexadecimal random tokens held in the URL fragment and hash-only storage. Creating a new link replaces the old one; links expire after 30 days or owner revocation. Redeeming requires a Poi account and now also grants shared expense access through confirmed event membership. A plain private event URL never grants access, and a missing requested event must never silently select another one. New expenses reuse the oldest shared event ledger; additional existing ledgers remain separately available, without rewriting splits or settlements.

This is still a browser companion, not complete native parity: background geofencing/reminders, native APK installation, the Android administrator console and UPI-app-specific handoff remain Android-only. Web theme styling is responsive and uses the same theme choices, not identical Compose screens. Google/phone provider configuration is unchanged.

Vendor: official `@supabase/supabase-js` 2.117.3 browser bundle from jsDelivr, MIT licensed. The SDK handles session persistence/refresh; the companion does not invent a separate authentication protocol. It is hosted as a public static Site using the normal authenticated Supabase client, not Sites/ChatGPT identity as a substitute for Poi accounts.

Run `node --check dist/app.js` and `node --test test/*.test.mjs`.

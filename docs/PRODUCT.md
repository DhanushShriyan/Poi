# Poi MVP product definition

## Promise

Poi is the trusted answer to: “What is happening around me, and which people I care about are joining?”

## Test persona and location

The offline test dataset uses Mangaluru and a local profile named Dhanush. These are replaceable seed values, not a locked launch decision.

## Current complete test loop

1. Discover and search nearby public, community, commercial, and private events.
2. Review trust level, organizer, time, venue, friends, and privacy status.
3. Choose Interested, Going, or I’m here.
4. Select who can see a check-in.
5. See saved events in Plans.
6. Create and persist a new event.
7. Report inaccurate or unsafe content.
8. Configure privacy and reminder preferences.

## Deliberately deferred until cloud setup

- Real multi-user accounts and friend graph
- Server-side organizer verification
- Push delivery
- Photo/video upload and moderation
- Real event chat
- Poster OCR
- Ticketing and payments
- Google Maps embedded map

The screens expose the intended positions for these capabilities without pretending that a local APK can provide multi-user verification.

# Poi MVP product definition

## Promise

Poi is the trusted answer to: “What is happening around me, and which people I care about are joining?”

## Preview persona and location

An unconfigured debug build uses Mangaluru and a local profile named Dhanush as replaceable preview data. Connected builds use each account's synced profile and home area.

## Current complete test loop

1. Browse public content before sign-in, then create or use a real email account.
2. Discover and search nearby public, community, commercial, and permitted private events.
3. Select any-distance or a preferred nearby radius.
4. Review trust level, organizer, time, venue, friends, and privacy status.
5. Choose Interested, Going, or I’m here and select who can see a check-in.
6. See saved events in Plans and browse them by date.
7. Create and sync a public, circle, or invite-only event.
8. Add an event photo after attendance, then view, like, comment, share, or delete it.
9. Report inaccurate or unsafe content for protected administrator review.
10. Edit the synced profile, configure privacy, and permanently delete the account if required.
11. See connection health and retry a failed cloud refresh.
12. Receive a newer signed build through Poi after it is published from `main`.

## Deliberately deferred after Release 0.2

- Friend/follow graph and private invitation UI
- Push delivery
- Video moments and automated media moderation
- Real event chat
- Poster OCR
- Ticketing and payments
- Google Maps embedded map
- Production Google OAuth enablement and paid phone OTP delivery

These items require provider setup, additional moderation, or a later product release; Release 0.2 does not present them as already active.
